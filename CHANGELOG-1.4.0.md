# ТоргУчёт 1.4.0

## Что нового

Справочники «Контрагенты», «Сорта» и «Товары» можно заполнить из Excel. Откройте справочник: рядом с кнопкой «+ Добавить» появились кнопки «Скачать шаблон» и «Импорт из Excel».

### Шаблон

Шаблон скачивается прямо из программы. В нём:

- лист «Данные» — заголовки колонок, обязательные отмечены звёздочкой, первая строка — пример (её можно не удалять, программа её пропустит);
- лист «Инструкция» — что писать в каждой колонке;
- лист «Значения» — единицы измерения, страны, валюты, категории и сорта, которые уже есть в программе.

Подсказки к колонкам видны и при наведении на заголовок.

### Как проходит загрузка

1. Выберите файл: .xlsx или .csv, до 5 МБ и до 5000 строк. Старый формат .xls нужно пересохранить в Excel как .xlsx.
2. Выберите, что делать с записями, которые уже есть в справочнике:
   - **«Только добавить новые»** — найденные записи не меняются;
   - **«Добавить и обновить найденные»** — у найденных меняются только поля, заполненные в файле. Пустая ячейка ничего не стирает.
3. Программа покажет предпросмотр. У каждой строки статус: новая, обновление, пропуск или ошибка. Ячейки с ошибками подсвечены красным, с предупреждениями — жёлтым. Сверху — счётчики, по ним можно отфильтровать строки. Там же видно, какие категории и сорта будут созданы.
4. Нажмите «Загрузить N строк». Загружаются только строки без ошибок. Всё записывается одной операцией: если на каком-то шаге случится сбой, не запишется ничего.
5. После загрузки видно, сколько записей добавлено, обновлено и пропущено. Список ошибок можно скачать файлом Excel.

### Правила

- Контрагенты и сорта ищутся в справочнике по наименованию, без учёта регистра и лишних пробелов. Товары — по артикулу, а если артикула нет — по наименованию.
- Одна и та же запись дважды в файле — ошибка обеих строк.
- Если ИНН контрагента уже есть у другого контрагента, программа предупредит, но загрузку не остановит.
- Если сорт с таким наименованием уже есть, но код в файле другой, это ошибка строки — сорт не перезаписывается.
- Категории контрагентов и товаров, которых ещё нет, создаются автоматически. Неизвестные сорта в файле товаров тоже создаются. Всё это видно в предпросмотре заранее.
- Неизвестная единица измерения, страна или валюта — ошибка строки: их нужно сначала добавить в справочник.
- Единица, страна, сорт по умолчанию и доступные сорта сохраняются в карточку товара. В строки накладных они сами не подставляются, как и раньше.
- Загружать может тот, кто может добавлять записи в справочники. Если у пользователя раздел «Справочники» только для просмотра, кнопки импорта не показываются, а сервер такой запрос не примет.

Цены, остатки и штрихкоды из Excel пока не загружаются.

## Обновление

Обновляйте как обычно, через update.bat. В этой версии добавлена библиотека для чтения Excel; update.bat ставит её сам (шаг «Обновляю библиотеки»), поэтому нужен интернет.

Если архив распаковали вручную поверх старой версии, выполните в папке программы `npm install --omit=dev`. Без этого программа запустится и будет работать, но импорт из Excel покажет сообщение, что библиотека не установлена.

Изменений в базе данных нет.

Если после обновления страница белая (в консоли браузера 404 на файл `index-….js`), проверьте, что в папке `public` лежит `index.html` из версии 1.4.0 (внутри должна быть ссылка на `assets/index-DnRg75QN.js`), и обновите страницу через Ctrl+F5. Эта ошибка была в первом zip 1.4.0 и исправлена в пересобранном.
