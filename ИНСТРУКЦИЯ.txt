ТоргУчёт 1.1.0

ФАЙЛЫ
  start.bat          запуск программы (откроет браузер)
  backup.bat         резервная копия баз
  create-admin.bat   создать администратора / сбросить забытый пароль (режим одной базы)
  .env               настройки установки (создаётся из .env.example)

РЕЖИМЫ (строка MODE в .env)
  MODE=single   одна компания, одна база (клиентская установка). Вход по логину из базы.
  без MODE      несколько компаний и master-база (как раньше).

ВХОД ТЕПЕРЬ ЗАЩИЩЁН
  Сервер выдаёт подписанный пропуск при входе. Подделать пользователя или компанию в запросе нельзя.
  Неверный пароль 8 раз подряд: блокировка этого логина на 10 минут.
  После обновления все должны войти заново.

УСТАНОВКА У НОВОГО КЛИЕНТА (режим одной базы), вручную
  1) Установить PostgreSQL 18 и Node.js LTS.
  2) Создать пустую базу:   createdb -U postgres torguchet
  3) Загрузить структуру:   psql -U postgres -d torguchet -f schema_company.sql
     (файл schema_company.sql делается из рабочей базы командой pg_dump -s --no-owner --no-privileges)
  4) Скопировать .env.example в .env, оставить MODE=single, вписать пароль PostgreSQL в DATABASE_URL.
  5) Запустить create-admin.bat и создать администратора.
  6) Запустить start.bat. Недостающие поля базы добавятся сами (папка migrations).
  7) С других компьютеров сети открывать адрес, который сервер печатает при запуске
     («Для других компьютеров сети: http://192.168...»). В брандмауэре Windows разрешить порт 3000.

ОБНОВЛЕНИЕ СУЩЕСТВУЮЩЕЙ УСТАНОВКИ
  Закройте окно сервера, сделайте backup.bat, затем распакуйте новую версию поверх старой.
  Файлы .env, .auth_secret, schema_company.sql и папки node_modules и backup не затираются (их нет в архиве).
  Новые пакеты устанавливать не нужно.

СОЗДАНИЕ НОВОЙ КОМПАНИИ (режим нескольких компаний)
  SuperAdmin -> Компании -> Новая компания. Database URL:
    postgresql://postgres:ПАРОЛЬ@localhost:ПОРТ/имя_базы
  Для автоматического создания таблиц нужен файл schema_company.sql рядом с server.js.


=== ОБНОВЛЕНИЕ ПРОГРАММЫ (с версии 1.2.0) ===
1. Скопируйте файл обновления (TorgUchet.zip) на компьютер или флешку.
2. Закройте start.bat и браузер с программой.
3. Запустите update.bat, перетащите в окно файл zip, нажмите Enter.
   Он сам: сделает копию баз -> сохранит старые файлы -> заменит программу -> обновит библиотеки.
   Настройки (.env) и данные не затрагиваются.
4. Запустите start.bat. База обновится сама, в консоли будет строка «применены миграции».
Если что-то пошло не так: rollback.bat (возвращает программу). Копии баз лежат в папке backup\.
Резервная копия отдельно: backup.bat.


=== УСТАНОВКА У НОВОГО КЛИЕНТА ===
Нужно: Windows, PostgreSQL (запомнить пароль пользователя postgres), Node.js LTS (https://nodejs.org).
1. Распакуйте TorgUchet.zip в C:\  (получится папка C:\TorgUchet).
2. Запустите install.bat и отвечайте на вопросы: пароль PostgreSQL, название компании,
   логин и пароль администратора. Остальные вопросы можно пропускать Enter.
3. Установщик сам создаст базу, таблицы, справочники (рубль, единицы, склад, касса) и файл .env.
4. Запустите start.bat. С других компьютеров сети: http://АДРЕС-ЭТОГО-ПК:3000
   (адрес показан в окне start.bat; при необходимости разрешите порт 3000 в брандмауэре Windows).
Если установка не удалась, созданная база удаляется, и install.bat можно запустить заново.
