# ТоргУчёт

Локальная учётная система для торговли (Node.js + Express + PostgreSQL, веб-интерфейс в `public/`).

Текущая версия: **1.2.2**.

Установка и обновление — в файле [ИНСТРУКЦИЯ.txt](ИНСТРУКЦИЯ.txt).

Каталог `public/assets` — собранный фронтенд-бандл; исходный код фронтенда в репозиторий пока не входит.
